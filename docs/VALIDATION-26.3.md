# 26.3 实机验证记录

环境：Windows 11、JDK 25.0.1、Minecraft 26.3、Fabric Loader 0.19.5、
Fabric API 0.160.6+26.3、Sodium 0.9.2、NVIDIA RTX 5060 Laptop 8GB、驱动 616.92。
固定种子为 2632026，原版视距 6 区块，测试实例位于 `run-smoke/`。

## 已验证

| 项目 | 证据 |
| --- | --- |
| 原生 Vulkan 设备与必要特性 | 日志为 `minecraft=vulkan, renderer=native`；不创建第二个设备 |
| 持续区块摄入、网格生成、LOD 绘制 | 基本测试连续约 3,000 帧；585–632 个网格区段；正常保存退出 |
| 远景有效性 | 同机位 `smoke-800.png` 开启、`smoke-900.png` 关闭，远处树林/水域消失；重新创建后恢复 |
| 持久化状态 | 全部 35,723 种原版方块状态逐一写入/解码，状态对象完全相同；旧格式楼梯状态经过数据修复保留朝向 |
| 退出与缓存恢复 | 多次客户端重启读取同一数据库；没有清空缓存来绕过错误 |
| 区域导入 | 将隔离存档的 769 个区块导入全新内存数据库；88,095 次区段更新、332 种方块状态 |
| 渲染器生命周期 | 同世界销毁重建、资源包重载、主世界/下界/末地往返，原生缓冲/图像数量回到 28/6 |
| 参数变化 | FOV 70→90、原版视距 6→4、窗口 854×480→1024×576 |
| 透明与材质 | 经典透明和 26.3 OIT 下均有远景；截图检查树林、草地染色、水域、下界熔岩与环境雾 |
| 失败路径 | 注入存储创建失败后，世界清理和关闭在限定时间内完成，不再锁死清理线程 |
| 动态编辑 | 放置钻石块、发光石并移除；直接核对 Voxy 世界缓存中的方块状态与 15 级方块光 |

`artifacts/final-full/validation.log` 已通过核心及同步校验，未出现 VUID、同步 hazard
或 Voxy ERROR。路线连续移动 1,152 格并返回；结束时 1,764 个网格区段，
原生缓冲/图像维持 28/6，分配约 2,169/525 MiB。VMA 的整个宿主堆预算用量
约 2,992 MiB，不应误称为 Voxy 独占显存。

该次记录 6,286 个帧间隔：P50 32.304 ms、P95 34.732 ms、P99 35.499 ms，
最大 648.546 ms。这些值包含限帧、资源重载、维度加载和 Vulkan 校验开销，
不是无校验模式的性能基准，也不是单独的 GPU 耗时。
可追溯摘要及完整日志 SHA-256 见 [acceptance-summary.json](evidence/acceptance-summary.json)。

补充的 `artifacts/final-release/validation.log` 从清空测试方块开始再次验证放置、
发光和移除；保存退出后 Voxy 拥有的 GPU 缓冲与图像包装对象数量均为零，
同步校验同样通过。该次 2,938 个帧间隔 P50 为 16.671 ms、P99 为 34.613 ms。

## 已修复的运行期问题

* 26.3 栅栏等待参数按纳秒解释，旧实现实际只等待了 30 微秒。
* Vulkan 逻辑设备必须启用着色器使用的存储写入与 64 位整数特性。
* D32S8 与 D32 不是可互换的可变格式；采样应使用 D32S8 的深度 aspect。
* 新方块状态 codec 可以输出字符串，旧代码强制按 CompoundTag 读取导致重进崩溃。
* 世界创建抛出异常时必须释放写锁与数据库，否则退出会卡在世界清理线程。
* 移动时节点删除可能反复写同一 GPU 槽位，现合并为最终节点列表的一次上传。
* 模型上传批次可能多次修订相同地址，现只在目标范围重叠时插入传输屏障。
  修复前日志能被验收脚本正确拒绝，修复后相同路线通过同步校验。
* 原有摄入钩子会漏过未卸载区块内的放置操作；现在合并方块变化和光照变化，
  每个客户端世界按区段去重、每 tick 最多处理 128 个区段，避免每个方块都上传。

## 校验边界

Minecraft 的 AMD GPU 崩溃标记扩展在标题画面就触发 `vkCmdWriteBufferMarker2AMD`
的同步写入冲突。`-PsyncSmoke` 仅在独立测试模组内关闭 AMD/NVIDIA 崩溃标记，
保留完整同步校验；正常模组不带该测试注入。
参考 [LunarG 同步校验说明](https://vulkan.lunarg.com/doc/view/latest/windows/synchronization_usage.html)。

窗口大小切换时出现过一次 Minecraft `swapchain out of date` 警告，客户端自动
重建交换链并继续完成运行。Windows 系统性能计数器的启动警告来自 OSHI。

未将 Iris 光影包、第三方 Vulkan 替换模组、VR、回放模组或其他显卡驱动列为已验证。
短时测试不能替代多小时游玩或跨显卡测试。保留的 OpenGL/Blaze3D 代码不构成
26.3 支持声明。步行视角摇晃、全屏切换和复杂自定义资源包尚未专项验证。
